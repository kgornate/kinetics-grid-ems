# Kinetics Flutter Dashboard V2.4

## PCS navigation fix

- The PCS overview card is now clickable.
- A dedicated PCS item is added to the desktop navigation rail and compact navigation bar.
- The PCS screen displays all currently exposed PCS telemetry using categorized engineering sections and the searchable all-signals view.
- The screen listens to the shared GatewayController, so live REST/WebSocket updates continue while it is open.
- The card displays the PCS alarm count.
- No gateway configuration change is required beyond enabling PCS in the backend.
